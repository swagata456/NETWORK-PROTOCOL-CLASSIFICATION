# NETWORK-PROTOCOL-CLASSIFICATION
# Packet Length Prediction Using Machine Learning

> **Note:** The notebook is named `Network_Protocol_Classification.ipynb`, but the code currently performs a **regression task**: it predicts network packet length (`Length`) from the `PKN` value extracted from the `Info` column. It does not currently train a protocol-classification model.

## Project Overview

This project analyzes network packet data and uses machine learning regression models to predict packet length. The notebook loads a raw CSV dataset, cleans and validates network records, explores the cleaned data, extracts the `PKN` feature, and trains two regression models.

## Objectives

- Load and inspect network packet data.
- Clean the raw CSV records and validate source/destination IP addresses.
- Explore missing values, duplicate rows, packet protocols, and packet lengths.
- Extract the `PKN` value from the `Info` column.
- Predict packet length using `PKN`.
- Evaluate and compare Decision Tree and Random Forest regression models.

## Dataset

The notebook expects the input file:

`merged_youtube_live.csv`

The cleaning step creates:

`cleaned_gquic_dataset.csv`

The cleaned dataset contains these columns:

| Column | Description |
|---|---|
| `Source` | Source IP address |
| `Destination` | Destination IP address |
| `Protocol` | Network protocol |
| `Length` | Packet length |
| `Info` | Additional packet information |

The notebook extracts a numeric `PKN` feature from the `Info` column. **Both CSV files are required to run the notebook from the beginning; they are not included with this README.** Add the dataset files to the project folder or update the file paths in the notebook.

## Project Workflow

1. **Import libraries** – import the Python and Scikit-learn packages.
2. **Load raw data** – read `merged_youtube_live.csv`.
3. **Inspect raw records** – examine rows and the CSV structure.
4. **Clean data** – validate IP addresses and packet information, then write valid records to `cleaned_gquic_dataset.csv`.
5. **Explore data** – inspect data types, missing values, duplicates, summary statistics, protocol counts, and packet-length distributions.
6. **Feature extraction** – extract numeric `PKN` values from `Info`.
7. **Prepare model data** – use `PKN` as input (`X`) and `Length` as the target (`y`).
8. **Split data** – create training and testing sets using an 80:20 split and `random_state=42`.
9. **Train models** – train Decision Tree Regressor and Random Forest Regressor (`n_estimators=50`).
10. **Evaluate models** – calculate MAE, MSE, RMSE, and R²; compare MAE and plot actual versus predicted values.

## Machine Learning Models

### 1. Decision Tree Regressor
A tree-based regression model trained to estimate packet length from the `PKN` feature.

### 2. Random Forest Regressor
An ensemble of 50 decision trees. The notebook uses `random_state=42` and `n_jobs=-1`.

## Evaluation Metrics

- **MAE (Mean Absolute Error):** average absolute difference between actual and predicted packet lengths.
- **MSE (Mean Squared Error):** average squared prediction error.
- **RMSE (Root Mean Squared Error):** square root of MSE, expressed in the target's units.
- **R² Score:** indicates how well the model explains variation in the target values.

The notebook prints these metrics for both models and plots an MAE comparison. Actual metric values depend on the dataset and the notebook run; no fixed result is claimed here.

## Current Limitation

If the intended project is protocol classification, the target and model pipeline need to be changed to predict the `Protocol` column using classification algorithms.
